📱 AppLogin

Aplicativo Android desenvolvido em Java com foco em cadastro e autenticação de usuários.

🎯 Objetivo

O objetivo do aplicativo é permitir que o usuário realize cadastro e login através de telas simples e intuitivas.

🛠️ Tecnologias Utilizadas
Java
Android Studio
XML
📋 Funcionalidades

✅ Tela inicial
✅ Cadastro de usuário
✅ Login de usuário
✅ Validação de senha
✅ Navegação entre telas
✅ Interface simples e organizada

📱 Telas do Aplicativo
Tela Inicial
Botão Entrar

Usuário

▶️ Como Executar
Abrir o projeto no Android Studio
Sincronizar o Gradle
Executar em um emulador ou dispositivo móvel
Realizar cadastro
Efetuar login
