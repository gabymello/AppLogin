📱 AppLogin

Aplicativo Android desenvolvido em Java com foco em cadastro e autenticação de usuários.

🎯 Objetivo

O objetivo do aplicativo é permitir que o usuário realize cadastro e login através de telas simples e intuitivas.

🛠️ Tecnologias Utilizadas
• Java
• Android Studio
• XML

📂 Estrutura do Projeto
AppLogin
│
├── MainActivity.java
├── DBHelper.java
├── activity_login.java
├── activity_registrar.java
│
├── activity_main.xml
├── activity_login.xml
└── activity_registrar.xml

▶️ Como Executar
1. Abrir o projeto no Android Studio
2. Sincronizar o Gradle
3. Executar o aplicativo
4. Realizar cadastro
5. Fazer login
